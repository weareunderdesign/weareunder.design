# underground

`underground.md` is the record. everything on the page is in that one file, newest first. writing a note means typing at the top of it — no draft, no build, no queue. it is live the moment it lands.

a note looks like this:

```
## title
2026-08-16

the body, in plain markdown.

![](launch.png)

---
```

the `---` ends it. the next note starts under it. images and video go in this folder — drop the file in, write `![](name.png)`. a `.webm` or `.mp4` plays on its own, silent, looping.

write it in the spirit of every note before it — read them first. lowercase. plain. present tense. what it feels like, never how it's built. lead with the one thing that carries the note; fold the rest into a paragraph or two of prose, no bullets.

`index.html` and `marked.js` draw the page. you never need to open them.
