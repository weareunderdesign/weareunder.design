# underground

`underground.json` is the record. newest first. writing a note means adding an object to the top of it — there is no draft, no build, no queue. it is live the moment it lands.

an entry is `date`, `title`, `body`, `media`. `pinned` lifts one to the top. nothing else. a link belongs in the body, in markdown, like any other word.

`media/` holds images and webm. `type` is `image` or `video`, `src` is relative, `caption` is optional.

write it in the spirit of every note before it — read them first. lowercase. plain. present tense. what it feels like, never how it's built. lead with the one thing that carries the note; fold the rest into a paragraph or two of prose, no bullets.

`dna/` is what we believe. it changes rarely and it isn't a note.

distribution follows the delta: whatever is in the file and hasn't gone out yet, goes out.
